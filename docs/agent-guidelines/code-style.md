# Code Style

## Python

- Format with Black-compatible style.
- Require type hints for all function parameters and return values.
- Require Google-style docstrings for functions.
- Use architectural comments for complex or non-obvious design decisions.
- Avoid redundant line-by-line comments that restate code.

## JavaScript

- Format with Prettier using `tabWidth: 4`.
- Prefer expressive code and comments only where they add architectural clarity.
