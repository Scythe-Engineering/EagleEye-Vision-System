# Tests

Run the suite from the EagleEye repository root:

```bash
uv run pytest -q tests
```

The canonical test guide is in the [EagleEye documentation site](https://scythe-engineering.github.io/EagleEye-Docs/docs/codebase/testing). See the [synthetic video benchmark guide](https://scythe-engineering.github.io/EagleEye-Docs/docs/codebase/synthetic-video-benchmarks) for the opt-in Blender and replay workflows.
